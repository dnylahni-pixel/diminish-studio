# Diminish Super Admin — آزمایشگاه هوش داده و تصمیم‌گیری تجاری

یک بستر کنترلی پیشرفته (Control Plane) فارسی و RTL برای مدیریت حساب‌ها، سهمیه‌ها (Entitlement)، ممیزی تراکنش‌های مالی، کشف نشت درآمد و تصحیح زنجیره بالانس لجر (Ledger) بر روی پایگاه‌داده PostgreSQL و Drizzle ORM.

## 🚀 ویژگی‌های کلیدی پیاده‌سازی شده

این پروژه شامل **۱۵ موتور عملیاتی، محاسباتی و تصمیم‌یار فعال** است:
1. **مدل خواندنی User 360 / Account Intelligence**: تصویر جامع هر کاربر شامل اشتراک‌ها، فاکتورها، مانده اعتبار و مصرف.
2. **سنجش سلامت اشتراک و تحلیل ریسک ریزش (Churn)**: اختصاص نمره سلامت (۰ تا ۱۰۰) همراه با ریشه‌یابی خطاهای پرداختی و فرسایش.
3. **موتور محاسبه آبشاری MRR Waterfall**: ردیابی تحرکات درآمدی (New, Expansion, Contraction, Reactivation, Churn) به تفکیک ارز.
4. **موتور کشف نشت درآمد (Revenue Leakage)**: شناسایی فاکتورهای تاییدشده اما ناموفق، تراکنش‌های بدون سند فاکتور و اشتراک‌های بدحساب معلق‌نشده.
5. **مصالحه و توازن تاریخی لجر (Ledger Reconciliation)**: ردیابی انحراف بالانس نقدی کش‌شده با محاسبات ریاضی دقیق کل لاگ‌های اپند-اونلی لجر.
6. **تراکنش‌های اتمیک و چندمرحله‌ای رزرو/مصرف اعتبار**: با قفل ردیف‌های جدول دیتابیس (Row-level lock) و مجهز به مکانیزم مهار درخواست‌های تکراری (Idempotency Key).
7. **محاسبه پایداری و نرخ کسر شارژ (Burn Rate & Runway)**: محاسبه تعداد روزهای پایداری مانده اعتبار بر حسب الگوی مصرف غلتان و انقضای اعتبارات ۳۰ روز آینده.
8. **حل‌گر چندلایه‌ای سهمیه‌ها (Effective Entitlement)**: ادغام اتوماتیک محدودیت‌های پلن اصلی به همراه ملحقات افزونه‌ها (Addons) جهت ارائه سهمیه قطعی کلاینت.
9. **اعتبارسنج و تحلیل اختلاف نسخه‌های پلن (Plan Diff)**: بررسی دقیق افزایش قیمت کاتالوگ و حذف/اضافه سهمیه‌ها قبل از انتشار عمومی.
10. **کاشف وابستگی‌های دایره‌ای کاتالوگ (Dependency Cycles)**: مجهز به الگوریتم DFS به همراه بازسازی زنجیره چرخه جهت یافتن بن‌بست‌های فرآیندی کاتالوگ ویژگی‌ها.
11. **آنالیز مصرف غیرعادی (Usage Anomalies)**: با واریانس‌گیری پویا و نمره انحراف Z-Score (انحراف بالای ۲ به عنوان سیگنال غیرعادی / Anomaly).
12. **سنجش بازگشت سرمایه تخفیف‌ها و تبدیل تریال‌ها (Promo ROI)**: تحلیل آماری نرخ تبدیل دوره‌های آزمایشی و سوددهی کوپن‌ها در جذب MRR افزوده.
13. **سیستم توصیه اقدام مقتضی بعدی (Next Best Action)**: تصمیم‌سازی فعال (ارسال اخطار، پیشنهاد پکیج، بازبینی پرداخت) با درجه اطمینان و درجه اهمیت.
14. **کارت امتیازی سلامت و یکپارچگی داده‌ها (Data Quality Scorecard)**: مانیتورینگ جامع سیستم برای ردیابی رکوردهای منفی، مغایرت‌های لجر و ارجاعات یتیم.
15. **صف کارهای دارای اولویت اپراتور (Prioritized Operations Queue)**: لیست وظایف ممیزی برای ادمین، مرتب‌شده بر اساس نمره بحران از ۱ تا ۱۰۰.

## 🛠️ ساختار معماری پروژه

```text
src/
├── app/
│   ├── layout.tsx                      # چیدمان سراسری پروژه Next.js
│   ├── page.tsx                        # هوم‌پیج پرتال به همراه وضعیت اتصال دیتابیس
│   └── intelligence-lab/
│       ├── page.tsx                    # رابط کاربری فوق پیشرفته، کاملاً RTL و فارسی
│       └── actions.ts                  # کدهای سرور (Server Actions) برای کوئری و تراکنش‌های امن Drizzle
├── db/
│   ├── index.ts                        # مقداردهی اولیه اتصال Pool به پایگاه‌داده
│   └── schema.ts                       # کدهای Drizzle ORM شامل تعریف فیزیکی ۳۸ جدول اصلی و فرعی
└── features/
    ├── fixtures.ts                     # رکوردهای داده آزمایشی شبیه‌ساز (تغییر بالانس منفی، لجر ناتمام، چرخه‌ها)
    └── intelligence-engine.ts          # موتورهای تحلیل داده، منطق دامنه‌ها، الگوریتم DFS گراف و عملیات قفل اتمیک
```

## ⚙️ راه‌اندازی و دستورات اعتبارسنجی مستقل (No-Database Friendly)

یکی از افتخارات معماری این بسته، **استقلال کامل ساختاری** از وجود متغیرهای محیطی یا دیتابیس فعال در فاز تست و استقرار است. در غیاب دیتابیس، سیستم به صورت هوشمند روی `Demo Mode` با داده‌های تستی قطعی سوییچ می‌کند.

### ۱. اجرای اعتبارسنجی کدهای تایپ اسکریپت (TypeScript Compiler Check)
```bash
npm exec tsc -- --noEmit --pretty false
```

### ۲. اجرای کامپایل تولید و بهینه‌سازی (Production Build)
```bash
npm run build
```

### ۳. اعمال خودکار ساختار جداول به دیتابیس زنده (Drizzle Kit Push)
```bash
npx drizzle-kit push
```
*(این دستور در هنگام راه‌اندازی، تمام ۳۸ جدول کاتالوگ، بیلینگ و اعتبارات را بدون نیاز به فایل‌های مایگریشن دستی بر روی دیتابیس اعمال می‌کند.)*
