# CVE-2026-42349 in @clerk/clerk-react 5.61.3 (authorization bypass)

**ID:** vuln-0003
**Severity:** HIGH
**Found:** 2026-08-08 16:27:16 UTC
**Target:** Diminish Studio (diminish-studio monorepo, apps/diminish-studio user app)
**Package:** @clerk/clerk-react
**Ecosystem:** npm
**Installed Version:** 5.61.3
**Fixed Version:** 5.61.6
**CVE:** CVE-2026-42349
**CWE:** CWE-863
**CVSS:** 8.1
**Fix Effort:** Trivial

## Description

The Diminish Studio user application pins `@clerk/clerk-react@5.61.3` (resolved in `pnpm-lock.yaml`), which falls in the affected range `>= 5.9.0, <= 5.61.5` of CVE-2026-42349 — an authorization bypass in the official Clerk JavaScript SDK when combining organization, billing, or reverification checks. The advisory is fixed in `@clerk/clerk-react@5.61.6`.

## Evidence

**Advisory evidence:** `CVE-2026-42349` applies to `@clerk/clerk-react` at installed version `5.61.3`. The advisory is fixed in `5.61.6`.

**Usage analysis:** imported by application code; affected API usage unconfirmed. Direct import in application code: apps/diminish-studio/src/main.tsx:3 (`import { ClerkProvider } from '@clerk/clerk-react'`), apps/diminish-studio/src/App.tsx:6 (`import { useAuth } from "@clerk/clerk-react"`), apps/diminish-studio/src/pages/login.tsx:1 and apps/diminish-studio/src/pages/register.tsx:1 (`SignIn`/`SignUp`). The advisory's specific affected symbols (organization/billing/reverification check combination) were not found in application source; symbol-level usage of the affected API was not confirmed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

An authenticated user can bypass combined authorization checks (organization membership, billing entitlement, or reverification) enforced through the Clerk SDK, potentially gaining access to protected resources or actions they are not entitled to. Since the SDK is the authentication backbone of the user application, this undermines the authorization guarantees of every route relying on Clerk checks.

## Technical Analysis

`apps/diminish-studio/package.json:80` declares `"@clerk/clerk-react": "^5.61.3"` as a direct dependency and `pnpm-lock.yaml:1623` resolves it to exactly `@clerk/clerk-react@5.61.3` (single resolved version in the lockfile). CVE-2026-42349 (GHSA-w24r-5266-9c3c) describes an authorization bypass when organization, billing, or reverification checks are combined: an attacker with a lower-privileged session can pass the combined gate. The advisory's affected range `>= 5.9.0, <= 5.61.5` includes 5.61.3; the fix is 5.61.6.

## Remediation

Upgrade `@clerk/clerk-react` from `5.61.3` to `>= 5.61.6` in `apps/diminish-studio/package.json` (and any other workspace manifest that references it) and re-run `pnpm install` to update the lockfile. Verify no breaking changes in the minor bump and re-test sign-in/sign-up flows.
