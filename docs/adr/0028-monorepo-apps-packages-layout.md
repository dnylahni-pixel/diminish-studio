# چیدمان تک‌ریپویی با پوشه‌های apps/ و packages/

دو پروژه‌ی مرتبط که قبلاً در دو ریپو و دو سیستم بسته‌بندی جدا (diminish-studio با pnpm و super-admin-diminish با npm) زندگی می‌کردند، در یک workspace پن واحد با چیدمان استاندارد `apps/` + `packages/` ادغام شدند. پوشه‌های قبلی `artifacts/*` به `apps/*` و `lib/*` به `packages/*` منتقل شدند و اپ مدیریتی به‌صورت تازه (بدون تاریخچه‌ی بی‌ارزش ریپوی قبلی) در `apps/admin` با نام پکیج `@workspace/admin` قرار گرفت. ریپوی diminish-studio با remote موجود، مرجع واحد باقی ماند و `pnpm install` از ریشه، لاک‌فایل واحد می‌سازد. دستور `pnpm build` از ریشه ادمین را جدا می‌سازد (`pnpm --filter @workspace/admin build`) تا بیلد مشترک به env دیتابیس یا ماژول‌های native وابسته نباشد. ماژول‌های native مثل `better-sqlite3` باید در `onlyBuiltDependencies` ثبت شوند وگرنه pnpm اسکریپت build آن‌ها را اجرا نمی‌کند. حاکمیت Admin بدون تغییر باقی می‌ماند: تغییر `apps/admin` فقط با تأیید صریح مالک محصول مجاز است.
