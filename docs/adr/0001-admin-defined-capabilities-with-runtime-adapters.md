# قابلیت‌های تعریف‌شده در Admin با دریچه اجرای عمومی

مالک محصول هر قابلیت، کد پایدار، نوع، واحد، قیمت، محدودیت، وابستگی و عضویت آن در پلن‌ها را کاملاً از طریق Admin مدیریت می‌کند. User Application یک موتور عمومی برای اعمال این قوانین فراهم می‌کند و فقط زمانی کدنویسی جدید لازم است که رفتار نرم‌افزاری تازه‌ای ساخته و از طریق دریچه استاندارد قابلیت به موتور متصل شود؛ تغییر تنظیمات تجاری قابلیت نباید موتور یا عملکرد موجود را تغییر دهد.
