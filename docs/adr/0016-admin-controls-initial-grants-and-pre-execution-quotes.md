# Admin تعلق اولیه را کنترل می‌کند و هزینه به مسیر دقیق اجرا قفل می‌شود

تعلق خودکار یک دسترسی، پلن یا مزیت در بدو ورود باید از Admin قابل تنظیم باشد و در User Application hard-code نشود. هزینه عملیات پیش از اجرا محاسبه می‌شود، اما پیش‌فاکتور به اثر انگشت تغییرناپذیر همان کاربر، عملیات، منبع، محتوا، تنظیمات و نسخه قوانین قفل و تک‌مصرف است؛ تغییر هر ورودی آن را باطل می‌کند و اعتبار تجاری آن زمان‌محور نیست.
