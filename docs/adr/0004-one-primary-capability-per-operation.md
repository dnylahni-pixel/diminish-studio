# هر عملیات اجرایی یک قابلیت اصلی دارد

یک قابلیت می‌تواند چند عملیات اجرایی مرتبط داشته باشد، اما هر عملیات دقیقاً یک قابلیت اصلی برای بررسی دسترسی، قیمت‌گذاری و ثبت مصرف دارد. قابلیت‌های لازم دیگر از طریق dependencyهای Catalog بررسی می‌شوند تا هزینه‌گیری تکراری یا مبهم ایجاد نشود؛ مدل هزینه ترکیبی فقط با تصمیم صریح بعدی قابل اضافه‌شدن است.
