# API اتصال ابتدا یک Module مستقل داخل Admin است

API اتصال مدیریتی ابتدا به‌صورت Module مستقل داخل پروژه Admin ساخته می‌شود، اما قرارداد آن باید جداسازی آینده به یک سرویس مستقل را ممکن کند. User Application فقط با هویت سرویس کوتاه‌عمر به آن متصل می‌شود، کاربر را با شناسه داخلی معرفی می‌کند و کد قابلیت یا عملیات را از ورودی مرورگر نمی‌پذیرد.
