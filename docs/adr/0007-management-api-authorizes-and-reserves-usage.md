# API مدیریتی مرجع اجازه و رزرو مصرف است

User Application داده خام پلن و اعتبار را دریافت نمی‌کند تا خودش درباره اجازه تصمیم بگیرد. API اتصال مدیریتی کاربر، قابلیت، پلن، محدودیت و اعتبار را بررسی می‌کند، پیش از اجرا یک رزرو idempotent می‌سازد و مجوز اجرا برمی‌گرداند؛ User Application فقط نتیجه موفق یا ناموفق عملکرد را برای capture یا release گزارش می‌کند.
