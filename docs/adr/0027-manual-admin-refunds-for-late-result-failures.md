# بازگشت اعتبار نتیجه خراب فقط با تصمیم دستی Admin است

اگر پس از قطعی‌شدن هزینه مشخص شود نتیجه خراب یا غیرقابل استفاده بوده، سیستم فقط یک پرونده auditشده با شواهد عملیات ایجاد و آن را در Admin برجسته می‌کند. refund کامل، refund جزئی یا رد refund فقط با تصمیم دستی Admin انجام می‌شود و هر اقدام باید idempotent و متصل به عملیات و ledger اصلی باشد.
