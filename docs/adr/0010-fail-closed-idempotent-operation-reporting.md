# عملیات محدود fail-closed و گزارش نتیجه idempotent است

هر عملیات هزینه‌دار یا مصرفی شناسه یکتای اجباری دارد و قبل از اجرا از API مدیریتی مجوز و رزرو می‌گیرد. در قطعی API عملیات متوقف می‌شود؛ اگر ارسال نتیجه شکست بخورد، گزارش موفقیت یا شکست retry می‌شود ولی عملکرد واقعی دوباره اجرا نمی‌شود. cache فقط برای اطلاعات نمایشی مجاز است و بررسی نهایی همیشه با API انجام می‌شود.
