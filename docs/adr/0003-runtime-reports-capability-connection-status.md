# وضعیت اتصال قابلیت از Runtime گزارش می‌شود

Admin منبع حقیقت تعریف تجاری قابلیت است، اما نمی‌تواند اتصال فنی آن را دستی اعلام کند. User Application از روی دریچه‌های واقعاً ثبت‌شده وضعیت اتصال را تشخیص و به Admin گزارش می‌کند تا قابلیتی که هنوز پیاده‌سازی نشده به‌اشتباه آماده استفاده نمایش داده نشود.
