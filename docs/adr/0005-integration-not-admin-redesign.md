# هدف پروژه اتصال است، نه بازطراحی Admin

این پروژه در درجه اول باید User Application را به سیستم مدیریتی متصل کند. تغییر کد، schema، migration، تنظیمات، داده یا تجربه کاربری Admin مجاز است، اما فقط پس از تأیید صریح مالک محصول؛ هیچ Agent نمی‌تواند نیاز به اتصال را به‌تنهایی مجوز تغییر Admin تلقی کند.
