# قابلیت متصل‌نشده در User Application قابل اجرا نیست

قابلیت منتشرشده‌ای که فهرست اتصال Runtime برای آن عملیات واقعی گزارش نمی‌کند، مجوز اجرا دریافت نمی‌کند. Frontend می‌تواند آن را مخفی کند یا غیرفعال با پیام «به‌زودی فراهم خواهد شد» نمایش دهد؛ عملیات دارای مجوز زمان‌دار قبلی تا پایان اعتبار ادامه می‌یابد و درخواست تازه پس از غیرفعال‌شدن رد می‌شود.
