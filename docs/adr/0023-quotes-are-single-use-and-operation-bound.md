# پیش‌فاکتور تک‌مصرف و وابسته به مسیر دقیق عملیات است

اعتبار پیش‌فاکتور به گذشت چند دقیقه وابسته نیست، زیرا کاربر می‌تواند در آن بازه ورودی را عوض کند. هر پیش‌فاکتور به اثر انگشت تغییرناپذیر همان کاربر، عملیات، منبع و محتوای واقعی، تنظیمات و نسخه قوانین قفل می‌شود؛ هر تغییر آن را فوراً باطل می‌کند و پیش‌فاکتور فقط یک‌بار قابل مصرف است. timeout فنی cleanup موضوع جداگانه‌ای است و نباید قیمت یا مجوز کاربر را تعیین کند.
