# Admin می‌تواند قابلیت را هنگام اصلاح قوانین موقتاً متوقف کند

هنگام اصلاح قیمت یا قوانین یک قابلیت، مالک محصول می‌تواند گزینه توقف هنگام به‌روزرسانی را روشن کند. در این حالت Admin وضعیت توقف را واضح نمایش می‌دهد، درخواست تازه تمام کاربران مشمول با پیام «در حال به‌روزرسانی هستیم؛ کمی بعد دوباره تلاش کنید» رد می‌شود و قابلیت تا پایان اصلاح و همگام‌سازی قابل استفاده نیست. اگر توقف روشن نشود، نسخه همگام‌شده فعلی ادامه می‌یابد و تغییر پیش‌نویس تا همگام‌سازی رفتار runtime را عوض نمی‌کند.
