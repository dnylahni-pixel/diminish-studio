# عملیات بازیابی‌پذیر، منبع‌محور و بدون PII است

لغو، timeout و شکست رزرو را آزاد می‌کنند و recovery رزروهای فراموش‌شده را اصلاح می‌کند. عملیات می‌تواند شناسه منبع ارائه دهد تا اجرای تکراری هم‌زمان متوقف شود، و پاسخ‌ها و logها فقط کد دلیل ثابت و شناسه‌های داخلی را بدون email، token، URL فایل یا PII ثبت می‌کنند.
