# همگام‌سازی قوانین دستی و قرارداد اتصال نسخه‌دار است

انتشار تغییرات در Admin به‌تنهایی رفتار User Application را تغییر نمی‌دهد و مالک محصول باید همگام‌سازی قوانین را صریحاً اجرا کند. Interface اتصال نسخه‌دار است و هنگام ارتقا، نسخه قبلی تا به‌روزرسانی User Application پشتیبانی می‌شود تا انتشار دو سیستم باعث قطعی یا ناسازگاری نشود.
