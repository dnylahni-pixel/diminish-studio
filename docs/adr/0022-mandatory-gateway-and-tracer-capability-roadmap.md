# تمام قابلیت‌ها از درگاه عمومی عبور می‌کنند

هیچ Route محدود یا هزینه‌دار فعلی یا آینده حق دورزدن درگاه اعمال قوانین را ندارد. Roadmap جدید بر اساس Moduleهای عمیق و اتصال کامل مرحله‌ای نوشته می‌شود؛ ابتدا یک قابلیت ساختگی end-to-end معماری را اثبات می‌کند، سپس Analyze اولین قابلیت واقعی می‌شود و اصلاح امنیتی بحرانی Routeهای موجود به تصمیم‌های تجاری وابسته نمی‌ماند.
