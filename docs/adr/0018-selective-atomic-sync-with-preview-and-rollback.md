# همگام‌سازی انتخابی، atomic، قابل پیش‌نمایش و قابل بازگردانی است

مالک محصول می‌تواند مجموعه مشخصی از پلن‌ها و قابلیت‌ها را برای همگام‌سازی انتخاب کند، اما همان مجموعه باید کامل و بدون حالت نیمه‌منتقل‌شده اعمال شود. پیش از تأیید، تغییر قیمت‌ها، محدودیت‌ها و تعداد کاربران تحت‌تأثیر نمایش داده می‌شود و هر همگام‌سازی موفق امکان بازگشت سریع به نسخه قبلی دارد.
