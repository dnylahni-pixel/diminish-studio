# Runtime فقط از نسخه منتشرشده قوانین استفاده می‌کند

مالک محصول می‌تواند قابلیت، پلن، قیمت، محدودیت و وابستگی‌ها را در Admin به‌صورت پیش‌نویس تغییر دهد، اما User Application و API اتصال مدیریتی فقط نسخه صریحاً منتشرشده و پایدار را اجرا می‌کنند. تغییرات ناقص یا آزمایشی تا زمان انتشار نباید رفتار کاربران را تغییر دهند.
