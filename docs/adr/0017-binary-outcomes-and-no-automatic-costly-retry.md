# عملیات نتیجه دودویی دارد و شکست پرهزینه خودکار تکرار نمی‌شود

نتیجه قابل مشاهده عملیات تا حد امکان فقط موفق یا ناموفق است و stateهای میانی صرفاً برای recovery داخلی نگهداری می‌شوند. اگر یک فراخوانی خارجی با وجود ایجاد هزینه برای سیستم شکست بخورد، همان اجرای واقعی خودکار تکرار نمی‌شود، هزینه از کاربر قطعی نمی‌شود و رزرو او آزاد می‌شود. اجازه شروع تلاش تازه بر اساس هزینه واقعی شکست و آستانه‌های قابل تنظیم Admin تعیین می‌شود، نه صرفاً دستی یا خودکاربودن retry.
