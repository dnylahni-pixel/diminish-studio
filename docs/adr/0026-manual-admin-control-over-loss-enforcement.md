# اعمال محدودیت زیان فعلاً کاملاً دستی است

سیستم هزینه واقعی، زیان شکست و مجموع زیان هر کاربر را محاسبه و موارد مهم را هشدار می‌دهد، اما هیچ وضعیت اجرایی را خودکار تغییر نمی‌دهد. توقف یا اجازه retry، مسدود یا آزادکردن کاربر، تنظیم سقف‌ها و reset فقط با اقدام صریح Admin انجام می‌شود تا خطای تشخیص خودکار باعث محدودیت اشتباه کاربران نشود.
