# عملیات مدیریتی مجوزدار، auditشده و قابل هشدار هستند

انتشار، همگام‌سازی و rollback فقط برای مدیران دارای دسترسی مشخص ممکن است و تمام آن‌ها audit می‌شوند. مدت نگهداری مصرف، اعتبار، پیش‌فاکتور، عملیات و گزارش‌ها از Admin قابل تنظیم است و Admin برای شکست همگام‌سازی، رزروهای گیرکرده و افزایش شکست‌های خارجی پرهزینه هشدار می‌دهد.
