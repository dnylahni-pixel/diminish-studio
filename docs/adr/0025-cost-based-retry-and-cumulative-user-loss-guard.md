# هزینه شکست ثبت می‌شود و کنترل retry دستی است

Admin هزینه واقعی تمام عملیات موفق و ناموفق و مجموع زیان جذب‌شده هر کاربر را می‌بیند. عبور از سقف‌های تنظیم‌شده فقط هشدار با اهمیت بالا ایجاد می‌کند؛ اجازه یا توقف retry، مسدود یا آزادکردن کاربر، تغییر سقف و reset وضعیت فقط با اقدام دستی Admin انجام می‌شود و سیستم فعلاً حق تغییر خودکار این وضعیت‌ها را ندارد.
